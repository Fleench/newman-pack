# Newman Server Modpack

Welcome to the official modpack for the Newman server! This pack includes all the necessary server mods, plus client-side performance and visual boosters like Sodium and LambDynamicLights so you have the best experience right out of the gate.

## How to Install

Follow these steps to get connected to the server:

### 1. Install Prism Launcher
If you don't have it already, download and install [Prism Launcher](https://prismlauncher.org/download/). You will need this to easily import the modpack and manage your Minecraft instance.

### 2. Copy the Modpack Link
Right-click and copy the link address below (you just need the URL on your clipboard):

> **`https://raw.githubusercontent.com/Fleench/newman-pack/refs/heads/master/newman.mrpack`**

### 3. Import into Prism
1. Open **Prism Launcher**.
2. Click the **Add Instance** button in the top-left corner.
3. On the left sidebar, click **Import**.
4. Paste the URL you copied in Step 2 into the text box under *"Local file or link to a direct download:"*.
5. Click **OK**.

Prism will automatically download the correct version of NeoForge (1.21.1) and all the necessary `.jar` files directly from Modrinth. 

Once it finishes loading, simply double-click your new Newman instance to launch the game!

### Alternative: Local File Import
If the link doesn't work for you, you can manually download the file:
1. Download the `newman.mrpack` file directly from this repository.
2. Open Prism Launcher -> **Add Instance** -> **Import**.
3. Click the **Browse** button on the right.
4. Select the `newman.mrpack` file you just downloaded and click **OK**.
