Updating Your Newman Pack 🔄

Keep your settings and worlds safe while upgrading!

Update Instructions

  1. First, install the new Newman2.zip using Prism Launcher as a new instance. Check the installation guide if you need help!

  2. Right-click your old instance and select Folder to open its directory.

  3. Open the .minecraft folder. Your options.txt file is located directly in the root of this .minecraft instance folder! Copy this file so you don't lose your keybinds and settings!

  4. Also inside the .minecraft folder, copy your saves, resourcepacks, and schematics folders if you have them.

  5. Now, open the folder for your new Newman2 instance, go into its .minecraft folder, and paste the copied files! Replace any existing files when prompted.

  6. You're all set! Enjoy the fresh updates! 🎉
