Fresh Install Guide 🚀

Welcome, bro! If you're setting up the Newman Pack for the first time, you're in for a totally blessed experience. We're using Prism Launcher because it's based and incredibly clean. Let's get you set up!

1

Download Prism Launcher

First things first, grab Prism Launcher if you haven't already. It's the absolute GOAT for managing modpacks.

2

Download the Modpack

Make sure you have downloaded the Newman2.zip file from our holy repository. Don't extract it, just keep it safe in your Downloads folder!

3

Add Instance in Prism

Open Prism Launcher. Click the "Add Instance" button at the top left of the window.

4

Import from Zip

In the New Instance window, select "Import" from the left sidebar, then click "Browse" to find your Newman2.zip file.

5

Launch & Pray

Hit OK, wait for Prism to download the holy artifacts (mods), and double click the instance to launch! Praise be! 🙌
