How to Install (Prism Launcher)

Need the launcher? Download Prism Launcher

  1. Copy the direct URL for the modpack zip file below:

    https://raw.githubusercontent.com/Fleench/newman-pack/refs/heads/master/Newman2.zip

  2. Open Prism Launcher and click on Add Instance.

  3. Select Import from zip on the left side menu, paste the URL you copied above directly into the URL box, and click OK.

  4. Launch the game and praise God for this beautiful creation! 🙏
